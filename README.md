# 1st Hackathon – Elara

## ShipChat App

This was my first hackathon group project. We designed and developed a conversational shipping service prototype that helps users compare shipping options, track packages, and manage shipments through a modern chat interface.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Python
- Flask

### Features
- Chat-based shipping assistant
- Compare UPS, FedEx, and DHL shipping quotes
- Package tracking timeline
- Shipment history dashboard
- Modern responsive user interface

### My Contribution
I contributed to the design and development of the prototype and collaborated with my team during the hackathon.
